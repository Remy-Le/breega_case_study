# Northstar Cold Outreach Pipeline

A lead enrichment and personalization engine for B2B cold outreach — built as part of Breega's RevOps & Growth intern case study.

Turns a raw list of prospects into a fully enriched, ICP-scored, personalized CSV ready to plug into Instantly or Lemlist.

---

## What's Included

| File | Description |
|------|-------------|
| `pipeline.py` | End-to-end enrichment pipeline (source → enrich → score → personalize → export) |
| `northstar_dashboard.jsx` | Interactive React dashboard to explore pipeline output |
| `enriched_leads.csv` | Sample output — 20 enriched, scored, personalized leads |
| `northstar_strategic_plan.md` | Strategic plan: ICP definition, architecture, stack choices, 90-day roadmap |

---

## Pipeline Architecture

```
[1. SOURCE]  →  [2. ENRICH]  →  [3. SCORE]  →  [4. PERSONALIZE]  →  CSV export
Raw CSV          Tech stack       ICP fit          AI-generated           Ready for
or sample        Funding          0–10 score       email opener           Instantly /
dataset          Hiring signals   Tier A/B/C       + subject line         Lemlist
                 LinkedIn posts
```

### Scoring Model

| Signal | Points |
|--------|--------|
| Modern data stack (dbt, Snowflake, BigQuery…) | +1 or +2 |
| dbt specifically in stack | +1 |
| Funded in last 12 months | +2 |
| Funded in last 24 months | +1 |
| Headcount 50–300 (ICP sweet spot) | +1 |
| Actively hiring Data Engineers | +2 |
| Tier A persona (Head of Data, VP Data, CDO…) | +2 |
| Recent LinkedIn activity | +1 |

- **Tier A** (score ≥ 7): priority outreach, manual personalization review
- **Tier B** (score 4–6): semi-personalized sequence
- **Tier C** (score < 4): deprioritize

## Getting Started

### Requirements

- Python 3.10+
- Node.js 18+ (for the dashboard only)

### Run the Pipeline

```bash
# Clone or download the files, then:

# Run on built-in sample dataset (20 European scale-ups)
python pipeline.py

# Run on your own prospect CSV
python pipeline.py --input your_leads.csv

# Enable AI-powered personalization via Claude API
python pipeline.py --input your_leads.csv --api-key sk-ant-...

# Custom output path
python pipeline.py --input your_leads.csv --output output/enriched.csv
```

### Input CSV Format

Your input CSV should have these columns (all optional except `first_name`, `last_name`, `company`):

```
first_name, last_name, title, company, company_domain, linkedin_url, email
```

### Output CSV Columns

```
tier, icp_score, first_name, last_name, email, title, company, company_domain,
linkedin_url, funding_round, funding_amount_m, months_since_funding,
headcount, headcount_growth_pct, data_team_size, tech_stack,
hiring_data_engineers, recent_linkedin_post,
personalization_line, email_subject, score_breakdown
```

## Running the Dashboard

### Option A — VS Code / local

```bash
npx create-react-app northstar-dashboard
cd northstar-dashboard

# Copy the dashboard file
cp /path/to/northstar_dashboard.jsx src/App.jsx

# Install Tailwind
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

In `tailwind.config.js`:
```js
content: ["./src/**/*.{js,jsx}"]
```

In `src/index.css`, replace everything with:
```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

```bash
npm start
# Opens at http://localhost:3000
```

### Option B — instant (no setup)

Paste `northstar_dashboard.jsx` into [stackblitz.com/edit/react](https://stackblitz.com/edit/react) or [codesandbox.io](https://codesandbox.io) and replace `App.js`. Runs immediately — good for demos.

## Personalization Logic

Without an API key, the pipeline uses a rule-based system that prioritizes signals in this order:

1. **Recent LinkedIn post** — highest relevance, references specific content
2. **Active DE hiring** — scaling signal, ties directly to governance pain
3. **Recent funding** — budget unlocked, growth pressure active
4. **dbt in stack** — strongest technical governance signal
5. **Modern data stack** — general fit indicator
6. **Title/persona** — fallback when no other signal available

With `--api-key`, each opener is generated by Claude with full enrichment context injected into the prompt.

## Case Study Context

Built for **Northstar**, a B2B SaaS data governance product targeting data teams in European scale-ups (50–500 employees). Goal: double qualified demo pipeline from 8–10 to 16–20/month within 90 days, starting from a cold outreach baseline of <1% reply rate.

Full diagnosis, ICP definition, sequence strategy, and 90-day roadmap in [`northstar_strategic_plan.md`](./northstar_strategic_plan.md).
